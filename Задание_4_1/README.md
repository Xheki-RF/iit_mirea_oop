# Постановка задачи
В информационной системе технологической компании рассматриваются сотрудники разных ролей. Базовым объектом является сотрудник. На его основе определяются две роли: разработчик и менеджер. Также существует роль тимлида, которая совмещает функции разработчика и менеджера. Для моделирования такой системы необходимо построить ромбовидную иерархию классов.

**Базовый класс "Работник"**

В защищённом разделе:
1) строковое свойство имени сотрудника.

В открытом разделе:

1) конструктор с одним строковым параметром;
2) метод вывода имени сотрудника в формате "Employee::showName -> <имя>";
3) виртуальный метод вывода роли в формате "Employee::showRole -> Employee".

**Промежуточный класс "Разработчик"**

Класс должен:

1) наследоваться от класса Работник так, чтобы избежать ошибки;
2) содержать закрытое целочисленное свойство количества выполненных задач;
3) иметь конструктор;
4) иметь метод вывода количества задач в формате "Developer::showTasks -> <значение>";
5) переопределять виртуальный метод вывода роли в формате "Developer::showRole -> Developer".

**Промежуточный класс "Менеджер"**

Класс должен:

1) наследоваться от класса Работник так, чтобы избежать ошибки;
2) содержать закрытое целочисленное свойство количества проектов;
3) иметь конструктор;
4) иметь метод вывода количества проектов в формате "Manager::showProjects -> <значение>";
5) переопределять виртуальный метод вывода роли в формате "Manager::showRole -> Manager".

**Производный класс "Тимлид"**

Класс должен:

1) наследоваться от классов Разработчик и Менеджер;
2) содержать закрытое целочисленное свойство уровня руководства;
3) иметь конструктор;
4) иметь метод вывода уровня руководства в формате "TeamLead::showLevel -> <значение>";
5) иметь метод вывода имени сотрудника из класса Тимлид в формате "TeamLead::showLeadName -> <имя>";
6) иметь метод изменения имени сотрудника;
7) переопределять виртуальный метод вывода роли в формате "TeamLead::showRole -> TeamLead".

**Алгоритм работы программы**

1) Ввести имя сотрудника, количество выполненных задач, количество проектов, уровень руководства.
2) Ввести новое имя.
3) Создать объект производного класса, представляющего тимлида, используя введённые данные.
4) Вывести имя сотрудника через интерфейс базового класса.
5) Вывести имя сотрудника через интерфейс производного класса.
6) Изменить имя сотрудника с использованием функциональности производного класса.
7) Повторно вывести имя сотрудника через интерфейс базового класса.
8) Повторно вывести имя сотрудника через интерфейс производного класса.
9) Вывести количество выполненных задач.
10) Вывести количество проектов.
11) Вывести уровень руководства.
12) Создать три указателя:
    - на объект, рассматриваемый как разработчик;
    - на объект, рассматриваемый как менеджер;
    - на объект, рассматриваемый как сотрудник.
13) Направить все указатели(присвоить адрес) на созданный объект тимлида.
14) Через каждый из указателей выполнить вызов метода вывода роли сотрудника.

При решении задачи необходимо руководствоваться методическим пособием и приложением к методическому пособию. При решении задачи не допускается использование расширений языка, которые вы не в состоянии корректно описать в виде алгоритма (Например range-based for).

