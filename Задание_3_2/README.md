**Постановка задачи**

В системе мониторинга используется базовый датчик, который хранит внутренний калибровочный параметр и измеряемое значение. На основе базового датчика разрабатывается умный датчик, который наследует свойства базового датчика, но имеет собственные параметры с теми же именами.

Требуется разработать систему, которая

1) демонстрирует создание объекта производного класса;
2) демонстрирует сохранение доступа к открытым элементам базового класса;
3) демонстрирует сокрытие одноимённых элементов базового класса;
4) демонстрирует однозначное обращение к элементам базового и производного классов.

Базовый класс должен содержать:

1) в закрытом доступе:
    - одно свойство целого типа;
    - метод с одним параметром, который устанавливает значение закрытого свойства равным утроенному значению параметра.
2) в открытом доступе:
    - одно свойство целого типа;
    - параметризированный конструктор с двумя параметрами;
    - метод с двумя параметрами для изменения значений свойств;
    - метод вывода значений свойств в формате "Sensor: <закрытое свойство> <открытое свойство>"

Производный класс должен наследоваться от базового класса таким образом, чтобы к открытым элементам исходного класса сохранить открытый доступ и у него:

1) в закрытом доступе:
    - одно свойство целого типа с тем же именем, что и закрытое свойство базового класса.
2) в открытом доступе:
    - одно свойство целого типа с тем же именем, что и открытое свойство базового класса;
    - параметризированный конструктор;
    - метод изменения значений свойств;
    - метод вывода значений свойств в формате: "SmartSensor: <закрытое свойство производного класса> <открытое свойство производного класса>"

**Алгоритм работы программы**

1) Объявить две целочисленные переменные.
2) Ввести значения двух переменных.
3) Создать объект производного класса.
4) Вывести значения свойств базовой части объекта.
5) Вывести значения свойств производной части объекта.
6) Ввести одно целое число.
7) Присвоить это значение открытому свойству производного класса.
8) Присвоить это значение открытому свойству базового класса.
9) Вывести значения свойств производного объекта.
10) Вывести значения свойств базового объекта.
11) Ввести два целых числа a и b.
12) Если первое число больше нуля:
    12.1. вызвать метод установки свойств производного объекта с параметрами a+1 и b+1;
    12.2. вызвать метод установки свойств базового объекта с параметрами a-1 и b-1;
    12.3. вывести значения производного объекта;
    12.3. вывести значения базового объекта.
13) Иначе:
    13.1. вызвать метод установки свойств базового объекта с параметрами a+1 и b+1;
    13.2. вызвать метод установки свойств производного объекта с параметрами a-1 и b-1;
    13.3. вывести значения базового объекта;
    13.4. вывести значения производного объекта.
14) Завершить работу программы.

При решении задачи необходимо руководствоваться методическим пособием и приложением к методическому пособию
