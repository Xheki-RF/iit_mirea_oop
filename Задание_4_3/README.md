# Постановка задачи
В системе центра обработки данных выполняется регистрация устройств. Каждое устройство должно удовлетворять требованиям:
1) имя устройства не должно быть пустым;
2) мощность устройства должна быть больше нуля;
3) уровень нагрузки не должен превышать 100.

При нарушении этих условий система должна генерировать исключения.

**Класс Устройство**

Поля:
1) строковое поле имени устройства;
2) целочисленное поле мощности;
3) целочисленное поле нагрузки.

Методы:
1) конструктор, устанавливающий значения полей, проверяющий корректность данных, при ошибке генерирующий исключение:
    - Если имя пустое, сгенерировать исключение типа string со значением "Error: empty name";
    - Если мощность ≤ 0, сгенерировать исключение типа int со значением "-1";
    - Если нагрузка > 100, сгенерировать исключение типа double со значением "100.0"
2) метод вывода информации об устройстве в формате "Device::show -> <name> <power> <load>";

**Алгоритм работы программы**

1) Ввести количество устройств n.
2) Для каждого устройства:
    - Ввести значения имени, мощности и нагрузки.
    - Попытаться создать объект в блоке try.
        - Если объект создан успешно, вывести его данные.
        - Если возникло исключение, обработать его соответствующим блоком catch и вывести сообщение об ошибке.

**Формат обработки исключений**
1) для string: Exception(string): <текст>
2) для int: Exception(int): <значение>
3) для double: Exception(double): <значение>

Для корректного чтения имени допустимо использовать getline().

При решении задачи необходимо руководствоваться методическим пособием и приложением к методическому пособию. При решении задачи не допускается использование расширений языка, которые вы не в состоянии корректно описать в виде алгоритма (Например range-based for).
