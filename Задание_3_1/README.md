**Постановка задачи**

В компьютерной игре существует система предметов. Каждый предмет имеет имя и показатель прочности. В процессе работы программы предмет может быть отремонтирован, повреждён или создан как сломанный объект.

Одни операции должны изменять исходный предмет, другие — работать только с его копией. Также необходимо предусмотреть ситуацию, при которой сломанный предмет может отсутствовать.

Требуется разработать программную систему, содержащую один класс. Класс должен включать:

1) одно закрытое свойство строкового типа — имя предмета;
2) одно закрытое свойство целочисленного типа — прочность предмета;
3) конструктор по умолчанию (устанавливает по-умолчанию имя предмета Unknown и прочность 0);
4) конструктор с параметрами для установки имени и начальной прочности объекта;
5) конструктор копии;
6) деструктор;
7) метод увеличения прочности на заданное значение;
8) метод уменьшения прочности на заданное значение;
9) метод получения имени предмета;
10) метод получения прочности предмета.

Конструкторы и деструктор должны выводить сообщения  в следующем формате:

1) Item (Cnstr): <имя предмета>
2) Item (ParamCnstr): <имя предмета>
3) Item (CopyCnstr): <имя предмета>
4) ~Item (Dcnstr): <имя предмета>

Требуется реализовать следующие функции:

1) Функция, принимающая объект по ссылке и увеличивающая его прочность на 10.
2) Функция, принимающая объект по значению и уменьшающая его прочность на 5. Внутри функции повреждения вывести строку: "Inside damageItem: <имя> durability = <прочность>";
3) Функция создания сломанного предмета принимающая в качестве параметра целое значение - режим работы, возвращающая указатель на объект:
    - если введён режим 0, функция должна вернуть нулевой указатель;
    - в противном случае функция должна создать динамический объект со значениями:
        1. имя: Broken
        2. прочность: 0
        и вернуть указатель на него.

**Алгоритм работы программы**

1) Ввести имя предмета, начальную прочность и режим работы.
2) Создать объект с использованием конструктора с параметрами.
3) Передать объект в функцию ремонта.
4) Вывести:
    After repair: <имя> durability = <прочность>
5) Передать объект в функцию повреждения.
6) После возврата из функции вывести:
    After damage: <имя> durability = <прочность>
7) Вызвать функцию создания сломанного предмета.
    - Если возвращен нулевой указатель, вывести:
      Broken pointer is nullptr
    - Иначе вывести:
      Broken item: <имя сломанного предмета> durability = <прочность сломанного предмета>
8) Освободить динамическую память.
9) Завершить работу программы.

При решении задачи необходимо руководствоваться методическим пособием и приложением к методическому пособию
