# Постановка задачи

В информационной системе центра обработки данных ведётся учёт вычислительных устройств.

Каждое устройство имеет:

1) имя устройства;
2) уникальный номер устройства.

Кроме индивидуальных данных устройств, система хранит общую информацию:

1) общее количество созданных устройств;
2) текущее количество активных устройств.

Для реализации такой системы необходимо использовать статические поля класса.

**Класс Устройство**

Поля:

1) строковое поле имени устройства;
2) целочисленное поле уникального идентификатора устройства();
3) общее количество созданных устройств;
4) текущее количество активных устройств.
   Методы:
5) конструктор, сохраняющий имя устройства, увеличивающий счётчик созданных устройств, увеличивающий счётчик активных устройств, присваивающий уникальный номер устройства через счетчик созданных устройств.
6) деструктор, уменьшающий число активных устройств;
7) метод вывода данных объекта в формате "Device::show -> `<name>` `<id>`";
8) статический метод вывода данных о созданных и активных объектах в формате "Device::showStats -> created: `<value>` active: `<value>`"

**Алгоритм работы программы**

1) Ввести три имени устройств.
2) Создать:
   - один объект автоматически;
   - два объекта динамически.
3) Для каждого объекта вывести установленные данные.
4) Вывести информацию о кол-ве созданных и активных устройств.
5) Удалить первый динамический объект.
6) Вывести информацию о кол-ве созданных и активных устройств.
7) Удалить второй динамический объект.
8) Завершить программу.

При решении задачи необходимо руководствоваться методическим пособием и приложением к методическому пособию. При решении задачи не допускается использование расширений языка, которые вы не в состоянии корректно описать в виде алгоритма (Например range-based for).
