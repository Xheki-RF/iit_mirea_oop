**Постановка задачи**

В системе управления цифровыми устройствами используются два типа объектов. Первый тип описывает сетевые устройства, обладающие параметром скорости соединения. Второй тип описывает устройства хранения данных, обладающие объёмом памяти.

Некоторые устройства объединяют свойства обоих типов. Такие устройства называются сетевыми хранилищами. Они могут одновременно работать в сети и хранить данные. Для моделирования такой системы используются:
1) класс сетевого устройства;
2) класс устройства хранения данных;
3) класс сетевого хранилища, который наследует свойства обоих классов.

Требуется разработать систему, которая
1) демонстрирует использование множественного наследования;
2) демонстрирует создание объектов производного класса;
3) демонстрирует хранение указателей на объекты в контейнере vector;
4) демонстрирует обработку нулевого указателя;
5) демонстрирует изменение объектов контейнера по заданному условию.

**Класс сетевого устройства**

В закрытом разделе:
- целочисленное свойство скорости сети.
В открытом разделе
- параметризированный конструктор;
- метод изменения скорости;
- метод получения скорости.

**Класс устройства хранения данных**

В закрытом разделе
- целочисленное свойство объёма памяти.
В открытом разделе
- параметризированный конструктор;
- метод изменения объёма памяти;
- метод получения объёма памяти.

**Класс сетевого хранилища должен:**
1) наследоваться от двух базовых классов;
2) содержать строковое свойство имени устройства;
3) иметь конструктор с параметрами:
    - имя устройства;
    - скорость сети;
    - объём памяти;
4) иметь метод вывода информации об объекте. Метод вывода должен отображать: <имя> <скорость> <память>

**Алгоритм работы программы**

1) Ввести количество устройств.
2) Для каждого устройства ввести: <имя> <скорость> <память>
3) Для каждого устройства динамически создать объект сетевого хранилища и сохранить указатель на него в контейнере
4) После ввода всех устройств добавить в контейнер один нулевой указатель.
5) Вывести строку Initial state
6) Вывести информацию обо всех элементах контейнера:
    6.1. если указатель не равен nullptr, вывести информацию об устройстве.
    6.2. если указатель равен, вывести Empty pointer.
7) Ввести значение минимально допустимой скорости сети.
8) Для каждого элемента контейнера:
    8.1. если указатель равен nullptr, перейти к следующему элементу;
    8.1. если скорость устройства меньше введённого значения:
        8.2.1. удалить старый объект;
        8.2.2. создать новый объект с тем же именем и объёмом памяти;
        8.2.3. установить скорость сети равной 2 * введённое значение;
        8.2.4. сохранить указатель на новый объект в контейнере.
9) Вывести строку Modified state
10) Вывести информацию обо всех элементах контейнера в том же формате.
11) Освободить память, удалив все динамически созданные объекты.
